# Exalt Exchange Phase 1

Professional Binance-style small exchange starter for EXALT.

## Phase 1 includes
- Dark trading dashboard
- EXALT/USDT market
- Market board
- Buy/Sell panel UI
- Order book UI
- Recent trades UI
- Coin listing form
- Basic Node.js API backend

## Run backend
```bash
cd backend
npm install
npm start
```
Backend: http://localhost:3000

## Run frontend
Open a new terminal:
```bash
cd frontend
npm install
npm run dev
```
Frontend: http://localhost:5173
